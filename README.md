````````# Student Management System

A console-based Student Management System built in Java to manage student records.

## Features

- Add, delete, and update multiple student records
- Search student data using roll number
- Display all student data with a single selection
- View class average and list of below-average students
- Show class performance and topper
- Analyze subject-wise performance
- Display student rankings
- Compare performance statistics between boys and girls

## Technologies Used

- Java
- JDK
- IntelliJ IDEA

## Concepts Used

- Two-Dimensional Arrays
- Methods
- Switch Expressions
- Sorting Algorithms

## How to Run

1. Clone this repository.
2. Open `SMS.java`.
3. Run the `main()` method.
````````
