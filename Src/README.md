<h2>Student Management System</h2>
A console Based Student Management System built in java to Manage Student Records.

<h3>Features:</h3>
<ul>
<li>Add,Delete and Update Multiple Student data</li>
<li>Search Student data Using Roll number</li>
<li>Display All Student Data at a Single Selection</li>
<li>View Class Avg and List of Below Avg Student</li>
<li>Show Class Performance and Topper</li>
<li>Analyze subject-wise performance</li>
<li>Display student rankings</li>
<li>Compare performance statistics between boys and girls</li>

</ul>

<h3>Technologies Used</h3>
<ul>
<li>Java</li>
<li>JDK</li>
<li>Intellij IDEAA</li>
</ul>

</ul>
